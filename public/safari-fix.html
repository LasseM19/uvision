Safari laadt UVision niet?

Chrome werkt wel op je iPhone? Dan zit het probleem bijna zeker in oude Safari-data of een content blocker — niet in je netwerk.

Location blocked?
  1. In Safari, tap the menu left of the address bar (Aa or ☰)
  2. Website Settings → Location → Allow
  3. Return to UVision and tap Enable live location or Use my current location

If you tapped Don't Allow before, Safari will not ask again until you change Website Settings or remove site data below.

Stap 1 — Automatische reset

Open deze link in Safari (niet Chrome):

Open reset-pagina
Stap 2 — Safari website-data wissen (meest effectief)
  1. iPhone Instellingen
  2. Apps → Safari
  3. Geavanceerd → Websitegegevens
  4. Zoek uvision of vercel
  5. Tik → Verwijder
Stap 3 — Content blocker uit
  1. In Safari, tik links in de adresbalk op Aa
  2. Zet Content Blockers uit voor deze site
  3. Herlaad de pagina
Open UVision opnieuw

Werkt Safari nog steeds niet? Gebruik UVision tijdelijk in Chrome op iPhone — daar werkt hij al bij jou.
